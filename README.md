🐾 PET LOVE
Una tienda virtual pensada para el bienestar, el cuidado y la felicidad de perros y gatos.

DESCRIPCIÓN DEL PROYECTO
Es un proyecto de desarrollo web que busca ofrecer una experiencia de compra cómoda, intuitiva y agradable para las personas que desean cuidar y consentir a sus mascotas.
La plataforma está orientada a la venta de productos para perros y gatos, incluyendo alimentos, accesorios, camas y juguetes. 
También cuenta con una sección de servicios para facilitar la atención de las necesidades de los clientes y sus mascotas.
El proyecto combina diseño visual, organización de productos y funcionalidades interactivas para crear una tienda virtual accesible y fácil de utilizar.

  OBJETIVO
- Desarrollar una tienda virtual de productos para perros y gatos.
- Facilitar la exploración y selección de productos mediante un catálogo organizado.
- Ofrecer una experiencia de navegación intuitiva y adaptable a diferentes dispositivos.
- Incorporar funcionalidades de usuario, carrito de compras y solicitud de servicios.
- Implementar una estructura que permita integrar una base de datos y gestionar la información de manera organizada.

CARACTERÍSTICAS PRINCIPALES
- **Página de inicio:** presenta la identidad de PET LOVE y permite acceder a las diferentes secciones de la tienda.
- **Catálogo de productos:** organiza los productos para facilitar su exploración.
- **Detalle de productos:** permite consultar la información de cada producto.
- **Carrito de compras:** reúne los productos seleccionados por el usuario.
- **Gestión de usuarios:** contempla el registro, el inicio de sesión y el perfil del cliente.
- **Servicios:** presenta las opciones de atención ofrecidas por la tienda.
- **Solicitud y seguimiento de servicios:** permite enviar solicitudes y consultar el estado de las respuestas.
- **Página de contacto:** ofrece un espacio para consultar la información de contacto de la tienda.
- **Diseño adaptable:** busca facilitar la navegación tanto en computadores como en dispositivos móviles.


TECNOLOGIAS UTILIZADAS
| HTML5 - Estructura y contenido de las páginas web. 
| CSS - Diseño visual, estilos, colores, distribución y adaptación a diferentes pantallas. 
| JavaScript - Interactividad y comportamiento dinámico de la tienda. 
| Neon (PostgreSQL) - Base de datos prevista para almacenar y gestionar la información del sistema. 
| Git y GitHub - Control de versiones y administración del código fuente. 


DISEÑO
PET LOVE utiliza una identidad visual inspirada en el cuidado y el cariño hacia las mascotas.
La propuesta gráfica se caracteriza por:

- Tonos morados y lavanda.
- Fondos crema y degradados suaves.
- Tarjetas con una distribución visual organizada.
- Botones y elementos de navegación consistentes.
- Una interfaz diseñada para ofrecer una experiencia agradable y profesional.
